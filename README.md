# FluentPath AI — pacote de plugin particular (v0.1.0)

Contém uma habilidade pedagógica portátil para ChatGPT: `fluentpath-professor`.

## Inclusões
- Currículo CEFR A1-C2 e microsequência A1 M1.
- Diagnóstico, aulas, correção item a item e regra de 100% de domínio.
- Reforço adaptativo focado em pré-requisitos.
- Orientação para voz, pronúncia, escuta e conversação com capacidades disponíveis.
- Revisão espaçada e modelo de registro exportável.
- Adaptação a Duolingo e outras ferramentas sem substituir currículo.
- "Progressão de aprendizagem" com barras somente com percentuais comprovados.

## Limitações v0.1
Não inclui servidor, banco de dados, app interativo próprio, TTS/MP3, acesso automático à conta do Duolingo nem notificações programadas. Ao usar, recursos de voz, exercícios e flashcards dependerão das funções disponibilizadas pelo ambiente.

## Próxima versão planejada
Se houver infraestrutura para MCP hospedado, adicionar estado persistente individual, painel dinâmico de CEFR, banco de itens de avaliação, agendamento de revisão, integração autorizada com provedores de áudio e painel do aluno.
